# Ruslan Emelyanov — Portfolio

## Запуск локально
Откройте `index.html` в браузере. Изображения находятся в папке `assets/`, поэтому не перемещайте HTML отдельно от этой папки.

## Публикация на GitHub Pages
1. Загрузите `index.html`, папку `assets/` и этот README в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Нажмите **Save**.

Фотографии вынесены в отдельные файлы, чтобы HTML не превышал лимит загрузки GitHub.
